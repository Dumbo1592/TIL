WSL(Windows Subsystem for Linux): Windows 안에서 리눅스를 실행할 수 있게 해주는 기능.
우분투: 컴퓨터에서 프로그램을 실행하고 파일을 관리하는 운영체제, 설치 도구, 기본 프로그램, 업데이트 기능 등을 묶어 사용하기 쉽게 만든 리눅스 배포판
Docker: 프로그램과 실행에 필요한 환경을 하나로 묶어서 실행하는 도구, 협업시 개발환경을 통일하기 수월함

pwd         # 현재 폴더 위치 확인
ls          # 파일과 폴더 목록 보기
cd ~        # 내 홈 폴더로 이동
mkdir test  # test 폴더 만들기
