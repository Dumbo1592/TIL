머신러닝이란?
데이터로부터 패턴과 규칙을 학습하여 새로운 데이터에 대한 예측이나 판단을 수행하는 기술

기존 프로그래밍: 
데이터 + 직접 작성한 규칙 = 결과

머신러닝 학습(지도학습 기준):
데이터 + 정답 = 학습된 모델

인공지능: 인간의 지능적인 행동을 컴퓨터로 구현하는 기술
머신러닝: 데이터를 통해 패턴과 규칙을 학습하는 기술
딥러닝: 다층 인공신경망을 활용하는 머신러닝 기술
LLM: 대규모 텍스트 데이터로 학습한 언어 모델

머신러닝의 종류:
머신러닝은 학습 방식에 따라 크게 지도학습, 비지도학습, 강화학습으로 구분할 수 있다.

지도학습: 입력 데이터와 그에 해당하는 정답을 함께 제공하여 모델을 학습시키는 방식
비지도학습: 정답이 없는 데이터를 제공하고, 모델이 데이터 내부의 패턴이나 구조를 스스로 발견하도록 하는 학습
강화학습: 모델이 환경에서 행동을 수행하고, 그 결과로 얻는 보상을 기반으로 장기적으로 더 많은 보상을 얻을 수 있는 행동을 학습하는 방식

회귀: 연속적인 수치를 예측할 때(집값, 시험점수, 매출액), 독립변수
분류: 데이터가 속하는 범주를 예측한다(합격 여부, 불량 여부, 스팸 분류), 결정 결계

5. 머신러닝의 전체 개발 과정

01 문제 정의
무엇을 예측할 것인가?

02 데이터 수집
CSV, API, 데이터베이스 등

03 데이터 분석 (EDA)
분포, 상관관계, 이상치 확인

04 데이터 전처리
결측치, 인코딩, 스케일링

05 특성 선택 및 데이터 분할
Feature Selection, Train / Test

06 모델 선택 및 학습
LinearRegression, RandomForest 등

07 모델 평가
MAE, MSE, Accuracy 등

08 모델 최적화
교차 검증, 하이퍼파라미터 조정

09 배포 및 모니터링
실제 서비스 적용 및 성능 관리

데이터 분석(EDA):
Exploratory Data Analysis의 약자로, 모델을 학습시키기 전에 데이터의 특성과 구조를 파악하는 과정
df.info(), df.describe(), df.isna().sum(), df.corr(numeric_only=True)

데이터 전처리(Data Preprocessing):
수집한 데이터를 머신러닝 모델이 학습하기 적합한 형태로 가공하는 과정

결측치 처리: 누락된 데이터 제거 및 대체
이상치 처리: 비정상적인 데이터 확인 및 처리
인코딩: 범주형 데이터를 수치로 변환
스케일링: 특성 간 수치 범위 조정
특성 선택: 불필요한 독립변수 제거
특성 공학: 기존 데이터로부터 유용한 특성 생성

데이터 분할(Data Split)
모델의 학습에 사용한 데이터와 성능을 평가할 데이터를 분리하는 과정
학습 데이터: 모델을 학습 시키는데 사용
검증 데이터: 모델 및 하이퍼파라미터 선택에 사용
테스트 데이터: 최종 성능 평가

과적합과 과소적합:
머신러닝의 목적은 기존 데이터를 완벽하게 기억하는 것이 아니라, 학습하지 않은 새로운 데이터에 대해서도 정확하게 예측하는 것

구분	         학습 데이터 성능	      새로운 데이터 성능
과소적합            낮음                  낮음
적절한 적합         높음                  높음
과적합           매우 높음             상대적으로 낮음
