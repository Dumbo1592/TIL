힙(Heap)과 우선순위 큐
============================================================

1. 언제 사용하는가?
------------------------------------------------------------
값이 계속 추가되는 상황에서 최솟값·최댓값을 반복해서 꺼낼 때 유용하다.

활용 예시
- 가장 작은 값 두 개를 반복해서 합치기: 카드 정렬, 더 맵게
- 우선순위가 높은 작업부터 처리하기: 작업 스케줄링, 이벤트 시뮬레이션
- 거리가 가장 짧은 후보부터 처리하기: 다익스트라 최단 경로
- 많은 값 중 가장 큰 K개만 유지하기
- 최소 힙과 최대 힙을 함께 사용하여 중앙값 유지하기

선택 기준
- 전체를 한 번 정렬하려면: sorted()
- 최솟값·최댓값을 한 번만 찾으려면: min(), max()
- 값의 추가와 최솟값·최댓값 꺼내기를 반복하려면: 힙
- 특정 값의 존재 여부를 빠르게 확인하려면: set, dict


2. 우선순위 큐와 힙의 차이
------------------------------------------------------------
우선순위 큐: 우선순위가 높은 데이터를 먼저 꺼내는 추상적인 자료형.
힙: 우선순위 큐를 구현할 때 자주 사용하는 구체적인 자료구조.

일반 큐는 먼저 넣은 데이터를 먼저 꺼낸다(FIFO).
우선순위 큐는 넣은 순서보다 우선순위를 기준으로 꺼낸다.
작은 숫자를 높은 우선순위로 볼지, 큰 숫자를 높은 우선순위로 볼지는 문제에 따라 정한다.

우선순위 큐는 배열, 연결 리스트, 힙 등으로 구현할 수 있다.
힙은 삽입과 최우선 원소 삭제를 모두 효율적으로 처리하는 일반적인 선택이다.
모든 상황에서 힙이 가장 효율적인 것은 아니다.


3. 이진 힙의 구조와 규칙
------------------------------------------------------------
여기서 설명하는 힙은 알고리즘 문제에서 흔히 사용하는 '이진 힙'이다.
이진 힙은 완전 이진 트리이며 최소 힙과 최대 힙으로 나뉜다.

완전 이진 트리
- 마지막 레벨을 제외한 모든 레벨이 채워져 있다.
- 마지막 레벨은 왼쪽부터 빈자리 없이 채워진다.
- 트리 높이가 O(log N)으로 유지된다.

최소 힙: 부모 값 <= 자식 값 → 루트가 최솟값
최대 힙: 부모 값 >= 자식 값 → 루트가 최댓값

최소 힙 예시

        1
       / \
      3   2
     / \
    7   5

배열 표현: [1, 3, 2, 7, 5]

주의
- 부모와 자식 사이의 대소 관계만 보장한다.
- 형제끼리 또는 다른 가지의 노드끼리 정렬되어 있다는 보장은 없다.
- 예시에서 2가 3보다 뒤에 있어도 올바른 최소 힙이다.
- heap[1]이 두 번째로 작은 값이라는 보장은 없다.
- 중복값을 허용한다. 부모와 자식의 값이 같아도 된다.
- 이진 탐색 트리의 중복 허용 여부는 구현 정책에 따라 다르다.


4. 배열 인덱스와 원소 이동
------------------------------------------------------------
완전 이진 트리를 배열(파이썬에서는 리스트)에 레벨 순서로 저장한다.
0번부터 시작하는 방식과 1번부터 시작하는 방식 모두 가능하다.

파이썬 heapq: 0번 인덱스부터 사용
- 루트: 0
- 왼쪽 자식: 2 * i + 1
- 오른쪽 자식: 2 * i + 2
- 부모: (i - 1) // 2  (i > 0일 때)

교재의 1번 인덱스 방식
- 루트: 1, 0번은 비워 둠
- 왼쪽 자식: 2 * i
- 오른쪽 자식: 2 * i + 1
- 부모: i // 2  (i > 1일 때)

//는 정수 나눗셈이다. 자식 인덱스가 배열 범위 안인지 확인해야 한다.
위치에 붙인 인덱스는 일정하지만, 그 위치에 저장된 원소는 바뀔 수 있다.
삽입·삭제 과정에서 값을 교환하므로 특정 원소의 인덱스는 고정되지 않는다.


5. 동작 원리와 시간 복잡도
------------------------------------------------------------
삽입: 마지막 자리에 추가한 뒤, 부모와 비교하며 위로 올린다.
루트 삭제: 마지막 원소를 루트로 옮긴 뒤, 적절한 자식과 비교하며 아래로 내린다.
최소 힙은 더 작은 자식, 최대 힙은 더 큰 자식과 비교한다.

N은 원소 개수이며, 값 한 번의 비교를 O(1)로 가정한다.

          작업                시간 복잡도
최솟값 확인(최소 힙의 루트)         O(1)
삽입                           O(log N)
최솟값 꺼내기                   O(log N)
리스트 전체를 힙으로 변환           O(N)
N개를 하나씩 꺼내기            O(N log N)
특정 값 탐색(별도 인덱스 없음)      O(N)

최대 힙도 대칭적으로 같은 복잡도를 가진다. 저장 공간은 O(N)이다.
파이썬 리스트의 크기 확장 비용까지 고려하면 삽입은 분할 상환 기준이다.


6. 파이썬 최소 힙 기본 코드
------------------------------------------------------------
heapq는 표준 라이브러리이므로 별도 설치가 필요 없다.
아래 예제들은 각각 독립적으로 실행할 수 있다.

import heapq

heap = [7, 3, 5, 1, 2]
heapq.heapify(heap)             # 원본 리스트를 최소 힙으로 변환
heapq.heappush(heap, 0)         # 원소 추가

if heap:                       # 빈 힙이면 접근·꺼내기에서 IndexError 발생
    print(heap[0])             # 0: 확인만 하고 제거하지 않음
    print(heapq.heappop(heap))  # 0: 최솟값을 제거하고 반환

while heap:
    print(heapq.heappop(heap))  # 1, 2, 3, 5, 7

주의: heap = heapq.heapify(heap)처럼 대입하지 않는다.
heapify()의 반환값은 None이므로 위처럼 대입하면 heap이 None이 된다.


7. 최대 힙 코드
------------------------------------------------------------
[방법 A] 숫자 부호를 반대로 저장: 이전 파이썬 버전에서도 사용 가능

import heapq

heap = []
for number in [5, 1, 9, 3]:
    heapq.heappush(heap, -number)

while heap:
    print(-heapq.heappop(heap))  # 9, 5, 3, 1

[방법 B] Python 3.14 이상에서는 최대 힙 전용 함수 제공
현재 설정된 Python 3.15.2에서도 사용 가능하다.
온라인 채점 환경의 파이썬 버전은 별도로 확인해야 한다.

import heapq

heap = [5, 1, 9, 3]
heapq.heapify_max(heap)
heapq.heappush_max(heap, 7)
print(heap[0])                  # 9
print(heapq.heappop_max(heap))  # 9


8. 우선순위 큐 코드: 동점이면 입력 순서 유지
------------------------------------------------------------
튜플은 첫 번째 값부터 순서대로 비교한다.
(우선순위, 값)만 넣으면 동점에서 값끼리 비교한다.
값이 dict처럼 대소 비교가 안 되는 자료형이면 TypeError가 날 수 있다.
고유한 순번을 두 번째에 넣으면 값끼리 비교하지 않고 입력 순서도 유지된다.

import heapq
from itertools import count

heap = []
sequence = count()  # next()를 호출할 때마다 0, 1, 2, ... 반환

heapq.heappush(heap, (2, next(sequence), {"name": "작업 A"}))
heapq.heappush(heap, (1, next(sequence), {"name": "작업 B"}))
heapq.heappush(heap, (2, next(sequence), {"name": "작업 C"}))

while heap:
    priority, order, task = heapq.heappop(heap)
    print(task["name"])  # 작업 B → 작업 A → 작업 C


9. 가장 큰 K개만 유지하는 코드
------------------------------------------------------------
최소 힙에 큰 값 K개를 보관한다.
힙이 가득 차면 현재 보관 중인 최솟값과 새 값을 비교한다.

import heapq

k = 3  # 양의 정수
heap = []

for number in [5, 1, 9, 3, 7, 2]:
    if len(heap) < k:
        heapq.heappush(heap, number)
    else:
        heapq.heappushpop(heap, number)

print(sorted(heap, reverse=True))  # [9, 7, 5]

heappushpop(): 새 값을 넣고 최솟값을 꺼내는 효과. 빈 힙에서도 사용 가능.
heapreplace(): 기존 최솟값을 먼저 꺼내고 새 값을 넣음. 빈 힙에서는 오류.
두 함수는 결과가 다를 수 있으므로 무조건 서로 바꾸면 안 된다.

이미 가진 데이터에서 한 번만 K개를 고르려면 다음 함수도 사용 가능하다.
heapq.nlargest(k, data)   # 큰 값 K개를 내림차순 리스트로 반환
heapq.nsmallest(k, data)  # 작은 값 K개를 오름차순 리스트로 반환


10. 실수하기 쉬운 부분
------------------------------------------------------------
- heap 전체를 출력하거나 for로 순회해도 정렬 순서가 나오지는 않는다.
- 일반 append()나 인덱스 대입으로 값을 바꾸면 힙 규칙이 깨질 수 있다.
  삽입은 heappush()를 쓰고, 일괄 수정했다면 heapify()로 다시 정리한다.
- 최소 힙 함수와 최대 힙 함수를 같은 리스트에 섞어 쓰지 않는다.
- 같은 우선순위의 입력 순서는 기본적으로 보장되지 않는다.
  입력 순서가 필요하면 예제처럼 고유한 순번을 넣는다.
- 임의 원소 삭제나 우선순위 변경은 heapq가 직접 제공하지 않는다.
  문제에 따라 새 항목을 넣고 오래된 항목은 꺼낼 때 무시하는 방식을 쓴다.
- 다익스트라는 음수 간선이 없는 그래프에서 사용한다.
  (거리, 정점)을 넣고, 꺼낸 거리가 기록된 최단 거리보다 크면 건너뛴다.
