1. vsCode 실행 방식: 코드의 분석, 자동완성, 오류 감지

Pylance: VS Code에서 Python 코드의 분석, 자동완성, 오류 감지를 담당하는 언어서버
즉, Pylance는 코드를 실행하는 도구가 아니라, 코딩하는 동안 실시간으로 코드를 분석하고 개발을 보조하는 도구

언어서버: IDE에서 작성하는 코드를 실시간으로 분석하고, 분석 결과를 IDE에 전달하는 프로그램

LSP 프로토콜: IDE와 언어 서버가 코드 분석 정보를 주고 받기 위한 표준 통신 프로토콜
JSON-RPC 2.0: 그냥 제이슨 파일 형태로 요청, 응답을 주고받는 규약
Pylance, Pyright: 실제 코드를 분석하고 결과를 반환하는 프로그램

실제 동작 방식:
vs Code(자동완성 요청) -> LSP(textDocument/completion 요청 정의) -> JSON-RPC 2.0(요청 정보를 JSON 메세지로 구성) -> Pylance(코드 분석 및 자동완성 후보 반환)

2. Work Space 실행 방식: 코드의 분석, 자동완성, 오류 감지

PySide6: Python으로 데스크톱 GUI 프로그램을 만들 수 있게 해주는 라이브러리, C++ 기반의 GUI 프레임워크인 Qt6를 파이선에서 사용할 수 있도록 연결해주는 공식 바인딩
QCompleter: PySide6에서 제공하는 자동완성 UI 클래스
User(사용자 코드 입력) -> 후보수집(현재 파일의 단어 + 예약어 + 내장함수 + 사전등록 목록) -> QCompleter(입력값과 후보 비교)

타입 검사 --Pyright CLI
CodeEditor - 코드 변경 -> 2초 대기 (Debounce) -> 현재 코드를 임시 Python 파일로 저장 -> Pyright CLI 프로세스 실행 -> JSON 검사 결과 수신 -> 편집기에 오류 및 경고 표시
디바운싱으로 2초 대기 하는 이유는 키보드 누를 때 마다 Pyright를 실행하면 자원을 낭비하기 때문

4. 개선 방안
Pyright CLI를 반복 호출 하는 대신 Pyright Language Server로 실행하고, IDE에 LSP 클라이언트를 연결

Work Space IDE
       ↕
   LSP Client
       ↕
Pyright Language Server
       ↓
자동완성 · 타입 검사 · 함수 설명 · 정의 탐색

즉, 자체적으로 만들고 있는 자동완성 후보 수집 기능과 타입 검사 경로를 하나의 언어 서버 기반 구조로 통합가능
QCompleter는 유지하면서 후보를 수집하는 부분만 언어 서버의 분석 결과로 대체 가능, 일단 진행하면서 전체 소스코드의 호환성은 별도 확인 필요
------------------------------------------------------------------------------------------------------------------------------------------------
Before(total 2.6 sec)
1. 타이핑을 멈추고 2초 기다림
2. 파일을 임시로 저장
3. pyright(오류 검사 프로그램)를 새로 실행 → 프로젝트 전체를 처음부터 분석 → 결과 받고 종료
4. 다음에 또 고치면 1번부터 다시

After(total 0.6 sec)
파이썬 파일을 처음 열 때 pyright를 한 번 켜서 계속 띄워 둠(언어 서버)
타이핑하면 바뀐 부분만 0.3초 모아서 보냄
이미 분석해 둔 상태에서 바뀐 곳만 다시 확인 → 결과를 바로 돌려줌
------------------------------------------------------------------------------------------------------------------------------------------------
범용 연결 구조: pyright전용이 아닌 어떤 언어 서버든 사용 가능하게 설정
나중에 추가할 언어는 설정만 하면 사용가능
분할-이동과 연결: 같은 파일을 두 화면에 열어도 서버에는 한 번만 알리고, 탐색기에서 파일을 옮기면 새 경로로 이어서 검사
안정장치: 서버가 죽으면 한 번 다시켜고, 또 죽으면 예전 방식 불러옴, 앱을 닫으면 서버도 같이 꺼짐
