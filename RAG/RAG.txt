1. RAG란?
검색 증강 생성이라는 뜻으로, 
LLM이 답변을 생성 하기 전에 외부 데이터에서 관련 정보를 검색하고, 
검색한 정보를 바탕으로 답변을 생성하는 기술

일반적인 LLM은 학습 과정에서 얻은 지식을 기반으로 답변하지만, RAG를 적용하면 기업 내부 문서, 데이터 베이스,
PDF, 프로젝트 소스 코드 등 외부 정보를 참고하여 답변할 수 있다.

2. 일반 LLM과 RAG의 차이

일반 LLM:
사용자 질문 -> LLM(기존 학습 지식) -> 답변 생성

RAG 기반 LLM:
사용자 질문 -> 외부 데이터 검색 -> LLM(질문 + 검색된 정보) -> 답변 생성
